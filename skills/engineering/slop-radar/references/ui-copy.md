# UI copy tells

Load this when the target has meaningful copy: hero and section headlines, value props, feature cards, CTAs, pricing, empty states, and error messages. Long-form article and doc prose is out of scope; route it to the humanizer skill.

Copy tells follow the same finding threshold as visual tells: one phrase alone is weak evidence, a pattern repeated across sections is strong, and a documented brand voice can justify a convention. Quote the exact string as evidence. Report the pattern; do not rewrite the copy.

## Headline rhetoric

| Tell | Shape | Example |
|---|---|---|
| Binary contrast | "Not X. It's Y." / "It's not just X, it's Y." | "Not just a CRM. A growth engine." |
| Negative listing | "Not a X. Not a Y. A Z." | "Not a tool. Not a platform. A partner." |
| Faux-insight setup | Claims hidden knowledge before the point | "What most teams get wrong about onboarding" |
| Colon reveal | Noun phrase, colon, dramatic reveal | "The secret: it learns from you." |
| Rhetorical setup | Question or teaser the next line answers | "What if your docs wrote themselves?" |
| Fake-profound kicker | Closing aphorism or mic-drop line | "Because great work deserves great tools." |

Correction: state the claim directly ("Tracks every deal from first call to renewal").

## Unsupported claims

- **Importance puffery**: "a pivotal shift", "a testament to", "redefines how teams work".
- **Weasel attribution**: "experts agree", "studies show", "trusted by industry leaders" with no named source.
- **Vague benefits**: "boost productivity", "unlock growth", "work smarter" where a specific fact belongs.

These cost trust, which is a Fitness consequence. Correction: replace with a sourced, specific fact, or cut the claim. Never invent the number, customer, or source.

## Portability test

Could this headline, value prop, or claim move unchanged to a competitor's site, with nothing product-specific to explain it? Then it weakens specificity and counts toward Defaultness. Shared category language ("Sign up", "Pricing") and concrete capabilities competitors also have (SSO, CSV export) are not tells.

## Buzzwords

Examples, not a ban list: leverage, streamline, robust, seamless, cutting-edge, game changer, supercharge, elevate, empower, unlock. A buzzword is a tell when it replaces a concrete claim, not merely when it appears.

## Em dashes

In short UI copy (buttons, headings, card text, labels), any em dash is a tell. In longer passages, flag clusters and decorative use, not a single well-placed dash.
